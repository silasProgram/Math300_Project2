# Math300_Project2
This is our project 2 on the Dijkstra's Algorithm. 
When using the rand_graphs function you are able to input the number of vertices and the number of edges. By default the number of edges is equal to the number of vertices but you can increase this number with j. If you input a negative number for j it will not break the code but any number less then -1 will cause some the vertices to not be used since our graphs are defined by their edges. The maximum number of edges that can be in a graph is (v*(v-1))/2 if you go over that number the code will break.
